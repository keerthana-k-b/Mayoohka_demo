# Your Brand &mdash; Asset &amp; Image Specification Guide

This guide provides the complete inventory, recommended dimensions, aspect ratios, and photography specifications for all 68 media files used across the **Your Brand** contemporary apparel storefront.

---

## 1. Quick Reference & Format Standards

* **File Format**: Modern `.webp` is recommended for all photographic assets for optimal web compression and clarity. The brand logo badge uses `.png` with transparency.
* **Target File Size**: Under **60 KB** per image (maximum 100 KB for hero banners).
* **Color Space**: sRGB for consistent cross-browser and mobile display.
* **Aspect Ratios**:
  * **Hero Banners**: `2:3` (720 × 1080 px)
  * **Collection Cards**: `5:7` (600 × 840 px)
  * **Product Catalog**: `3:4` (600 × 800 px)
  * **Story / Mosaic**: `2:3` (600 × 870 px) & `10:7` (800 × 560 px)
  * **Social / Instagram**: `4:5` (600 × 750 px)
  * **Reel Posters**: `9:16` vertical (540 × 960 px)
  * **Reel Videos**: `9:16` vertical (1080 × 1920 px or 720 × 1280 px MP4)

## 3. Best Practices for Replacing Placeholders

1. **Keep Exact File Names**: Simply overwrite files with identical filenames (`collection-01.webp`, `product-01.webp`, etc.) to automatically populate all pages and dynamic templates without code modifications.
2. **Crop to Exact Aspect Ratios**: Maintaining the specified ratios (`3:4` for products, `5:7` for collections, `2:3` for hero) guarantees that layout cards remain uniform and visually balanced.
3. **Lighting &amp; Studio Consistency**:
   * Use diffuse, daylight-balanced natural lighting.
   * Maintain clean, neutral backdrops (warm beige, soft stone, off-white, or muted architectural settings).
   * Leave 8–10% breathing room around model borders to prevent tight edge cropping on smaller mobile displays.
4. **Compression Tools**:
   * WebP conversion can be performed easily with free web utilities such as [Squoosh](https://squoosh.app) or command-line `cwebp -q 80`.
